# Travokeys

Premium Next.js site for Travokeys Auto Locksmith in Crystal Park, Benoni.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build for production

```bash
npm run build
npm start
```

## Site features

- Six dedicated automotive locksmith service pages
- Resource hub with 20 long-form car-key and diagnostics articles
- Interactive service matcher and call-preparation tools
- WhatsApp click-to-chat links and call-to-action buttons
- Terms, Privacy & POPIA pages, SEO metadata, structured data, sitemap and robots rules

Business contact details are centralized in `app/content.ts`.
